AI × CAD 繪圖協作情報

最後更新：2026/11/17 08:01（台北時間）

本期判斷：AI × CAD 正同時走向原生整合與可驗證的「模型即程式碼」工作流 Autodesk 已把官方 AutoCAD／Civil 3D MCP 列為公開測試；ForgeCAD 則提供可直接由 Codex／Claude 登入的遠端 MCP，讓 agent 建立參數模型、執行碰撞／穩定性／模擬檢查，再輸出 STEP、BOM 與機器人套件。新出現的 SolidWorks 與 Solid Edge 社群方案開始用完全約束、dry-run、回讀驗證、權限分層、事件串流與 CAE 閉環證明結果；AutoCAD MCP Pro 1.8.0 更把持久化日誌、檢查點、原子寫入與交付後重開驗證做成可測量的復原鏈。Parametric CAD Bench v3 則顯示目前最佳完整系統平均也只有 61.03%，尤其建立後再修改僅約四成，提醒導入不能只看展示影片，必須用原生模型、幾何與規格一致性驗收。

監測範圍：直接控制繪圖軟體、自然語言轉參數／特徵、CAD API 與 MCP、DWG／DXF／STEP／工程圖後處理、驗證與可追溯工作流。

可導入：官方或產品化可試驗：已有可運行實作觀察：能力或風險待驗證

1. Fusion Assistant 正式擴充 BOM、組態規則與 MCP 工作流

可導入信心：高日期：2026/10/21工具：Autodesk Fusion、Assistant、MCP

Fusion v.2706.1.14 讓 Autodesk Assistant 可用自然語言批次更新 BOM 列、數量、成本、物理屬性與顯示範圍，也能依描述建立或修改 Configuration Rules。官方同時交付供 Assistant 與 MCP 工作流使用的 Search 技能，並分階段推出以組立替換 API 驅動的 Replace 技能；自動工程圖也正整合進 Assistant synthesis 工作流。既有三種 MCP 仍分別負責本機操作、雲端資料查詢與雲端運算。

實務含義：AI 已不只建立幾何，也開始直接改動 ERP 交接用 BOM 與設計規則。導入時應把欄位級權限、修改前後差異、組態規則測試與工程圖覆核列為必要控制；Replace 與自動工程圖仍屬分階段推出／整合中，不宜視為所有帳號均已可用。

來源：Autodesk Fusion 2026 年 10 月產品更新、Autodesk Support FAQ

2. ForgeCAD 遠端 MCP 讓 Codex／Claude 建模、驗證並輸出機器人資產

可試驗信心：高日期：截至 2026/11/2工具：ForgeCAD、Codex、Claude Code、MuJoCo／OpenUSD

ForgeCAD 提供需瀏覽器登入的遠端 MCP，Codex、Claude Code、Cursor 等 agent 可直接在雲端專案建立參數 CAD，渲染 3D／剖面，檢查碰撞、穩定性、參數組合與變體，或用 MuJoCo 對關節施加負載。輸出涵蓋 STEP、STL、3MF、GLB、BOM，以及 MJCF、USD、URDF、SDF 等機器人／模擬格式；連線也可由帳號頁撤銷。

3. Parametric CAD Bench v3 顯示 AI 繪圖仍有明顯可靠度落差

觀察信心：高日期：2026/11/2工具：FreeCAD、Claude Code、Codex、原生 FCStd 驗證器

Parametric CAD Bench v3 公布 100 項可重現測試：30 項文字建模、30 項先建模再修改，以及 40 項由工程圖重建機械零件。每個 agent 都在固定的 FreeCAD 環境中工作，交付原生參數模型給獨立程式驗證器；評分同時檢查幾何相似度、指定尺寸／規格一致性與可檢查的原生特徵結構，而不是只判斷腳本能否執行或截圖是否相似。

實務含義：截至 2026/9/24 的 13 組完整模型—agent 系統中，Claude Code＋Claude Opus 5.5 以 61.03% 總分最高，Codex＋GPT-6 Astra 為 56.87%；但不同工作流沒有單一贏家，Astra／Codex 在建立後修改領先也只有 44.37%。所有系統合計 30.23% 最終嘗試得零分，建立後修改更達 41.54%，證明企業驗收必須保留原生模型、尺寸檢查與失敗回滾，不能用「看起來像」取代工程驗證。

成本與速度：在已公開成本的組合中，Astra／Codex 每一得分點約 5.59 美元、平均每題 14.42 分鐘，為研究中較佳平衡；最高分的 Opus 5.5／Claude Code 約需 1.81 倍 API 成本與 2.25 倍時間。這些數字是特定版本、設定與 100 題樣本的完整系統結果，不代表模型本身的永久排名。

來源：Parametric CAD Bench v3 論文原文、版本化任務與結果網站

4. Autodesk 官方 AutoCAD／Civil 3D MCP 進入公開測試

可試驗信心：高日期：2026/10/23；可用性核對 2026/10/30工具：AutoCAD、Civil 3D、Autodesk Assistant

Autodesk 官方目錄新增本機 AutoCAD／Civil 3D MCP Server，標示為 Tech Preview（Public Beta），目前提供 7 項工具，可在已開啟圖面中查詢、分析、導覽及修改物件，也能依範本檢查圖面並操作 Civil 3D 樣式。官方支援說明同時限定：伺服器在本機產品內由 Autodesk Assistant 使用，目前唯一受支援的 AI 用戶端就是 Autodesk Assistant。10 月 30 日更新的 Assistant FAQ 另確認 AutoCAD 需 2026 以上版本，而較新的 Assistant 體驗只在最新產品版本提供，實際能力也會依產品與地區而異。

實務含義：AutoCAD／Civil 3D 終於有原廠可核對的代理操作基線，適合先以副本測試物件修改、範本 QA 與樣式工作流；但採購前需按版本、帳號與部署地區實測可用性。Codex、Claude 等外部用戶端目前不在官方支援範圍，也不能把「採用 MCP」直接解讀為可任意更換 AI 主機。

來源：Autodesk MCP Server 官方目錄、Autodesk MCP 支援說明、Autodesk Assistant 可用性 FAQ

7. SolidCraft 0.30.1 收緊 agent 授權並統一 MCP 參數單位

可試驗信心：高日期：2026/11/2工具：SolidCraft、Codex／Claude 等 MCP 用戶端

SolidCraft 0.30.1 修正 agent chat 的權限判定：只有完整標題精確等於自身 MCP 工具名稱，且問題類型符合條件時才會自動回答，其餘授權問題改由既有權限模式、記憶規則或人工面板處理；控制通道的新連線也必須在 5 秒內提交 token，Windows 自訂控制目錄若無法安全設定 ACL，便不再寫入 token。另將 parameters.list、parameters.add 與 parameters.change 的 value 統一為毫米或角度，原單位數值另放在 display_value，舊腳本需檢查。前版 strict 參數檢查與組立件質量、重心、慣性回饋仍可搭配作為代理驗收防線。

8. AutoCAD MCP Pro 1.8.0 加入可復原、可驗證的持久化代理工作流

可試驗信心：高日期：2026/11/6；現況核對截至 2026/11/13工具：AutoCAD 2026、DXF、Claude／Codex 等 MCP 用戶端

AutoCAD MCP Pro 1.8.0 將代理操作日誌預設寫入 SQLite；即使重啟，仍能延續 drawing document ID、revision 與 client operation ID，並新增 checkpoint_create、checkpoint_list、checkpoint_restore、drawing_history 等工具。無 AutoCAD 的 headless DXF 寫入改為原子操作，也能以 drawing_open(recover=True) 將受損 DXF 讀入新的受保護版本線；交付流程會重開輸出檔並重新量測需求，而不是只信任代理曾送出的參數。

↗ 開啟 AutoCAD MCP Pro 專案

實務含義：這是少數把「代理失敗後怎麼復原」與「交付檔是否仍符合尺寸要求」列為正式能力的 CAD MCP。專案公布 83/83 headless 正確性檢查、47/47 可執行任務矩陣，以及 AutoCAD 2026 上 14 組 live smoke tests；但 COM 效能測試仍顯示部分大型幾何操作波動，live checkpoint 也拒絕原地覆寫、改以新文件開啟，試辦時應以複本、允許路徑與 HTTP bearer token 控制風險。

優先驗證方向

  1. 建立內部 CAD agent 基準：依 Parametric CAD Bench 的三類工作流，選公司零件建立文字建模、建立後修改與工程圖重建測試，分開計算幾何與規格一致性。
  2. AutoCAD 持久化復原鏈：刻意中斷寫入、重啟 MCP，再驗證 operation ID 去重、checkpoint 還原、DXF recover、輸出重開量測與 manifest 一致性。
  3. SolidWorks→ANSYS 可驗證閉環：用已知答案的零件與組立重跑完全約束、質量回讀、Parasolid 傳遞、接觸／網格、求解及失敗回滾。

建議評估問題

  1. 官方 MCP 是否限定 Autodesk Assistant，若改接 Codex／Claude，哪些功能、支援承諾與責任邊界會改變？
  2. 代理交付的是可編輯原生模型與正確特徵歷程，還是只有外形近似的靜態幾何；幾何與規格要如何分開驗收？
  3. 如何自動檢查單位、尺寸約束、干涉、材料、圖層與公司製圖標準，並把失敗率、時間與代理成本一併記錄？
