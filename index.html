1. Autodesk Flow Studio MCP 把可精修 3D 資產帶進 ChatGPT

可導入信心：高日期：2026/11/9工具：Autodesk Flow Studio、ChatGPT、Fusion、3D Editor

Autodesk 已在 ChatGPT 上線 Flow Studio MCP。使用者可從文字或參考圖產生最多四個 3D 草稿，查詢生成進度與既有資產，再以 Remesh 指定三角面數、以 Retexture 更換外觀，直接預覽或取得下載連結。資產會保存在 Flow Studio library，可轉入 3D Editor＋Canvas；Pro 用戶亦可用 Export to Fusion 將模型帶入 3D 列印與後續設計流程。

3. CivilCADBench 量出 AI 重建工程圖的圖層與跨頁落差

觀察信心：高日期：2026/11/21工具：多模態 AI、Python／ezdxf、DWG／DXF、獨立評分器

研究團隊用實際土木工程圖測試七種多模態模型，涵蓋 232 頁單頁重建、28 套跨頁重建與 19 項改參數後的設計任務。代理從黑白列印圖產生可編輯 DXF，評分器直接與原始 CAD 檔比對幾何、圖層、文字與尺寸。最佳單頁重建分數為 91.2，但同一模型在同批圖上的圖層感知 F1 為 59.9。

4. Maxon 讓 AI 在背景執行 Cinema 4D／Autograph

可導入信心：高日期：2026/11/23工具：Cinema 4D、Autograph、Redshift、Claude Code、ChatGPT／Codex

Maxon 推出獨立的 Agentic 月租授權。代理可透過 MCP 在本機或另一台電腦操作無介面的應用程式執行個體，每份授權同時支援一個執行個體，設計師仍可使用原本的互動工作環境。Cinema 4D 方案包含 Redshift，可批次製作產品配色、整理場景或產出渲染預覽。Autograph 方案則支援動態圖形及合成作業。

實務含義：試辦時可交給代理製作同一場景的配色變體，再確認專案可重開、相機與燈光一致，以及貼圖是否能在另一台電腦正確載入。AI 服務另外計費，授權也需獨立訂閱，評估時可把人工覆核和重跑時間計入成本。

來源：Maxon 官方公告、授權規格與支援的 AI 用戶端

6. FreeCAD AI 0.35 alpha 加入外部 MCP 代理連線介面

可試驗信心：高日期：2026/11/22（UTC）工具：FreeCAD、FreeCAD AI、Claude Code、MCP

8. MCP for Blender 連接 World Labs，讓 agent 生成可探索的 3D 世界

可試驗信心：高日期：2026/11/12–11/13工具：Blender 5.3、MCP for Blender、World Labs Marble、Codex／Claude

社群 MCP for Blender 2.2.8 加入 World Labs Marble：agent 可從文字、圖片或 360° 全景生成完整世界，將壓縮 Gaussian splats 載入 Blender 5.3，並附上隱藏碰撞網格、以公尺為單位且地面置於 z=0，方便放置物件與安排相機。2.2.9 隨後將伺服器封裝成 Claude Code plugin；Codex 仍可透過 codex mcp add blender -- uvx mcp-for-blender 連線。專案亦整合 Poly Haven、Poly Pizza、Meshy、Tripo、Hyper3D 與 Hunyuan3D 等資產來源。

優先驗證方向

  1. Inventor 參數回讀：在零件與組立副本修改尺寸，重算後比對原生檔、模型狀態及工程圖 PDF。
  2. FreeCAD 特徵驗收：從空白文件建模，重開 FCStd 後檢查草圖約束、特徵樹與修改尺寸後的重算結果。
  3. 工程圖重建：比對黑白圖與原始 CAD 檔的圖層、尺寸及跨頁共用數值。
