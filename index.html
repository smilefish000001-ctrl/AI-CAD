本期重大情報

1. Autodesk Assistant 在 Fusion 全面提供，並擴充為三種 MCP

可導入信心：高日期：2026/10/6工具：Fusion、Inventor、Vault、Moldflow

Autodesk 宣布 Assistant 已向所有 Fusion 使用者一般提供，可在產品內用自然語言完成設計與製造任務；官方 FAQ 進一步確認它能建立原生、可編輯的 3D CAD 幾何，而非靜態網格。Fusion 現有三種 MCP：本機操作建模與命令的 Fusion MCP、無須啟動 Fusion 即可查詢與管理資料的 Fusion Data MCP，以及讓 AI agent 在雲端執行設計與製造流程的 Fusion Compute MCP。

實務含義：企業可依資料位置與任務規模分流：互動建模走本機 MCP，PDM／專案查詢走 Data MCP，大量或無人值守流程走 Compute MCP。設計代理能力開始進入正式產品，但執行型功能會計入每月 Flex token，商用版目前每月包含 20 點。

來源：Autodesk Fusion Blog、Autodesk Support FAQ

2. Autodesk 正式推出 Fusion MCP，Claude 可即時操作 3D 設計

可導入信心：高日期：2026/5/7–5/14工具：Autodesk Fusion、Claude

Autodesk 推出官方 Fusion MCP，讓 AI 連接本機執行中的 Fusion，透過自然語言建立、修改、查詢草圖、特徵與 3D 幾何。Anthropic 的連接器頁面也將其列為 Autodesk 製作、Anthropic 驗證的整合，且連線在本機執行。

3. Fusion AutoTimeline 將把無歷史幾何重建為可編輯參數模型

觀察信心：高日期：2026/9/16工具：Autodesk Fusion

Autodesk 預告 AutoTimeline 會以 AI 特徵辨識，從匯入或 direct-mode 的無歷史幾何重建可編輯的參數化設計歷程；同批能力還包括自動辨識元件並建立組立關係的 AutoAssemble，以及由自然語言建立大量有效產品組態的 Assistant。

4. AutoCAD MCP 已能讓 Codex／Claude 操作圖元、圖層、圖塊與尺寸

可試驗信心：中高日期：截至 2026/10/8工具：AutoCAD 2026、Codex、Claude

5. AutoCAD 市集已有產品化 MCP，可批次修圖、修復外部參照與更新圖框

產品化信心：高日期：截至 2026/10/8工具：AutoCAD、AI Agent

Autodesk App Store 上的 AUTOM8LABS MCP Connector 已把 AI 工作流包裝成可安裝產品，支援套用繪圖標準、修復 Xref 路徑、批次修訂 DWG、更新 title block，以及準備 PDF 發行。

實務含義：市場正在從「讓 AI 畫一個零件」轉向「整理整批工程圖與交付文件」。這類規則明確、可抽樣驗證的後處理工作，通常比全自動設計更快產生可量化效益。

來源：Autodesk App Store

7. SOMA 0.8.0 把 Codex／Claude、參數 CAD、驗證與工程圖整合成桌面工作流

可試驗信心：中高日期：2026/10/13工具：Codex CLI、Claude Code、CadQuery、CalculiX

開源 SOMA 讓 Codex、Claude Code 等 CLI agent 以 Python／CadQuery 建立參數化模型，並提供建置、量測、碰撞、渲染與 FEM 指令讓 agent 檢查自己的結果。0.8.0 新增工程圖工作區，可把圖面視圖、剖面與尺寸連回 3D 模型，並輸出 STEP、STL、3MF、DXF 及多頁 PDF。

8. Revit 2027 推出可逐項審查變更的 Trusted-Write MCP

可試驗信心：高日期：2026/9/10工具：Revit 2027、Claude 等 MCP 用戶端

Autodesk 為 Revit 2027 推出三層 MCP 技術預覽：Read tools 可用自然語言查詢模型、屬性、報表與視圖；Trusted-Write 加入少量修改工具，並讓使用者審查 agent 對每個模型元素所做的變更；Experimental 則開放範圍更廣的建立與修改能力，但明確標示為自行承擔風險。

實務含義：這是工程 CAD／BIM 代理的重要治理範例：讀取、可信寫入與實驗寫入分層，且將人員審查放在模型變更流程內。企業試驗時應優先從 Read 或 Trusted-Write 開始，不應把 Experimental 直接用在正式模型。

來源：Autodesk Community 官方公告、Autodesk Revit 文件

優先驗證方向

  1. SOMA 工程圖閉環：用一個含公差與剖面的標準件，測試 Codex／Claude 從提示、量測修正到 STEP、DXF、PDF 的一致性。
  2. Fusion Assistant 三路徑：用同一個標準件比較本機 MCP、Data MCP 與 Compute MCP 的權限、延遲及成本。
  3. Revit Trusted-Write：用非正式模型測試逐元素變更審查、拒絕與回復是否完整可追溯。
