AI × CAD 繪圖協作情報

最後更新：2026/11/18 07:57（台北時間）

本期判斷：AI × 3D 繪圖正從外掛實驗走向原生、可控且可驗證的代理工作流 搜尋範圍擴大後，Autodesk Flow Studio MCP 已把可預覽、減面、重貼材質並轉入 Fusion 的 3D 資產工作流帶進 ChatGPT；Cinema 4D 2026.4 將 MCP 做成原生功能，V-Ray 7.50 也讓外部 agent 檢查與調整 SketchUp／Rhino 場景。McNeel 的 Rhino MCP Platform 0.4 強化 Codex 路徑、無頭工具與數值參數，而 Meshy × Blender 則把文字／圖片生成、拓樸縮減、場景組裝與渲染串成可量測流程。這些更新顯示 3D agent 的價值已從「生成一個模型」擴大到直接操作物件、材質、燈光、相機與輸出；但權限、程式碼執行、比例、拓樸、成本及原生可編輯性仍必須逐項驗證。CAD 端的 ForgeCAD、SolidWorks 閉環與 Parametric CAD Bench 也提醒：外觀相似不能取代尺寸、規格與原生結構驗收。

監測範圍：AI 直接控制 CAD／BIM／DCC／3D 軟體、自然語言轉參數與場景、MCP／API／外掛、自動生成或修改 3D 模型、材質、燈光、相機、動畫，以及 CAD、OBJ／FBX／GLB／USD／3MF 等輸出與可追溯驗證。

1. Autodesk Flow Studio MCP 把可精修 3D 資產帶進 ChatGPT

可導入信心：高日期：2026/11/9工具：Autodesk Flow Studio、ChatGPT、Fusion、3D Editor

Autodesk 已在 ChatGPT 上線 Flow Studio MCP。使用者可從文字或參考圖產生最多四個 3D 草稿，查詢生成進度與既有資產，再以 Remesh 指定三角面數、以 Retexture 更換外觀，直接預覽或取得下載連結。資產會保存在 Flow Studio library，可轉入 3D Editor＋Canvas；Pro 用戶亦可用 Export to Fusion 將模型帶入 3D 列印與後續設計流程。

實務含義：這不是只產生一張參考圖，而是能在同一對話中生成、減面、重貼材質、保存並轉往 3D 工具的產品化流程。導入前仍要測試尺寸精度、拓樸、UV／貼圖、下載格式與 Fusion 轉換品質；生成與精修會消耗 Flow Studio credits，且需 Lite、Standard 或 Pro 付費帳號。ChatGPT 經 OAuth 可存取獲授權的 Flow Studio 模型、專案與帳號基本資訊，權限範圍也應納入審查。

2. ForgeCAD 遠端 MCP 讓 Codex／Claude 建模、驗證並輸出機器人資產

可試驗信心：高日期：截至 2026/11/2工具：ForgeCAD、Codex、Claude Code、MuJoCo／OpenUSD

ForgeCAD 提供需瀏覽器登入的遠端 MCP，Codex、Claude Code、Cursor 等 agent 可直接在雲端專案建立參數 CAD，渲染 3D／剖面，檢查碰撞、穩定性、參數組合與變體，或用 MuJoCo 對關節施加負載。輸出涵蓋 STEP、STL、3MF、GLB、BOM，以及 MJCF、USD、URDF、SDF 等機器人／模擬格式；連線也可由帳號頁撤銷。

3. Parametric CAD Bench v3 顯示 AI 繪圖仍有明顯可靠度落差

觀察信心：高日期：2026/11/2工具：FreeCAD、Claude Code、Codex、原生 FCStd 驗證器

Parametric CAD Bench v3 公布 100 項可重現測試：30 項文字建模、30 項先建模再修改，以及 40 項由工程圖重建機械零件。每個 agent 都在固定的 FreeCAD 環境中工作，交付原生參數模型給獨立程式驗證器；評分同時檢查幾何相似度、指定尺寸／規格一致性與可檢查的原生特徵結構，而不是只判斷腳本能否執行或截圖是否相似。

實務含義：截至 2026/9/24 的 13 組完整模型—agent 系統中，Claude Code＋Claude Opus 5.5 以 61.03% 總分最高，Codex＋GPT-6 Astra 為 56.87%；但不同工作流沒有單一贏家，Astra／Codex 在建立後修改領先也只有 44.37%。所有系統合計 30.23% 最終嘗試得零分，建立後修改更達 41.54%，證明企業驗收必須保留原生模型、尺寸檢查與失敗回滾，不能用「看起來像」取代工程驗證。

成本與速度：在已公開成本的組合中，Astra／Codex 每一得分點約 5.59 美元、平均每題 14.42 分鐘，為研究中較佳平衡；最高分的 Opus 5.5／Claude Code 約需 1.81 倍 API 成本與 2.25 倍時間。這些數字是特定版本、設定與 100 題樣本的完整系統結果，不代表模型本身的永久排名。

來源：Parametric CAD Bench v3 論文原文、版本化任務與結果網站

4. Cinema 4D 2026.4 原生 MCP 讓 Codex／Claude 直接操作場景

可導入信心：高日期：2026/9/30工具：Cinema 4D 2026.4、Codex、Claude、ChatGPT

Maxon 在 Cinema 4D 2026.4 內建 MCP Server，AI 用戶端可透過產品 API 讀取並操作原生場景資料，包括物件階層、材質、相機、燈光、動畫、UV、rigging 與渲染佇列，也可建立 CSV 驅動的場景變體。伺服器預設關閉，連線需要 Adapter Access Token，管理者還能按工具群組限制可用能力；AI 執行的操作會進入 Undo 歷程，並保留本機稽核記錄。

實務含義：這是主流 3D DCC 將 agent 控制正式產品化的重要基線，適合先以非正式專案測試場景整理、批次材質／燈光、版本變體與渲染準備。啟用前仍應最小化工具群組、保護 token、限制可執行程式碼與檔案路徑，並確認 Undo／audit log 是否足以支援公司稽核。

來源：Maxon Cinema 4D 2026.4 發布說明、Cinema 4D MCP 官方功能頁、MCP Adapter 官方設定文件

7. Meshy × Blender MCP 串起生成、減面、場景組裝與渲染

可試驗信心：高日期：2026/10/22；教學更新 2026/10/27工具：Blender、Meshy 7.1、Codex、Claude Code

Meshy 已整合進 MCP for Blender，Codex、Claude Code、Cursor 等 agent 可由文字或參考圖生成帶 PBR 貼圖的 GLB，以真實世界比例匯入 Blender，再完成減面、物件配置、燈光、相機與渲染。官方案例以 job handle 處理長時間任務，六項資產約 25 分鐘、267 credits；其中高模由約 1,130 萬三角面縮減至約 24.5 萬，並可要求接近指定的 polygon budget。

實務含義：這類流程適合快速製作概念場景、遊戲資產與可視化原型，也提供時間、credits、比例與面數等可量化指標。它不等同工程 CAD：導入時要檢查拓樸、UV、PBR 通道、授權、比例、命名與 GLB／FBX／USD 交付品質。Blender MCP 可由 agent 執行 Python，應只在專案副本測試，限制腳本與檔案權限，API key 也不可貼入對話。

來源：Meshy 官方 Blender MCP 實作案例、Meshy 官方 Blender MCP 教學

8. SolidWorks MCP 以完全約束、回讀驗證與 CAE 閉環衡量成果

可試驗信心：中日期：2026/11/3–11/6工具：SolidWorks、ANSYS Mechanical、Claude 等 MCP 用戶端

新公開的 FullyDefined MCP 宣稱提供 121 項工具，涵蓋零件、鈑金、焊件、組立、工程圖、BOM 與 STEP／STL／PDF／DXF 輸出；每一步都回讀體積、質量、距離與草圖狀態，並公布以 SOLIDWORKS 官方練習題測得 22 件中 20 件落在答案 0.5% 內。另一個 SolidWorks＋ANSYS 專案把參數修改、Parasolid 匯出、組立模擬、結果擷取與下一設計點串成閉環；寫入後回讀，若狀態不符則標記 VERIFY_FAILED 並回滾，任意 IronPython 執行預設關閉。

優先驗證方向

  1. 3D 場景代理的治理防線：在 Cinema 4D、V-Ray 與 Rhino 以相同測試場景比較讀取、寫入、程式碼執行、工具權限、token、Undo、稽核記錄與失敗復原。
  2. 生成資產的工程化驗收：用 Meshy × Blender 固定一組參考圖與規格，記錄比例、面數、拓樸、UV、PBR 通道、GLB／FBX／USD 匯出、時間與 credits。
  3. 建立跨 CAD／DCC 內部基準：同時評估原生可編輯性、參數／場景結構、幾何與規格一致性、圖片結果及代理修改後的可重現性。

建議評估問題

  1. 代理交付的是可繼續編輯的原生模型／場景、正確參數與物件階層，還是只有靜態網格或攤平輸出；再次修改時會保留哪些結構？
  2. 哪些工具只讀、哪些能寫入或執行程式碼；是否有逐項批准、最小權限、token 保護、Undo、稽核記錄與可驗證的失敗復原？
  3. 如何自動驗證比例、尺寸、拓樸與面數、UV／PBR 材質、相機／渲染設定、輸出格式及原生檔，並同時記錄時間、credits 與人工修正量？
